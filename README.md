# Ashwin Krishnaswamy — Simulations

Interactive physics and dynamics simulations, hosted on GitHub Pages.

## Adding a simulation

1. Save the simulation's HTML as `sims/<name>/index.html`.
2. In `index.html`, copy the `<a class="card">` block and update the link, title, description, and tags.
3. Commit and push. The site updates within a minute or two.
